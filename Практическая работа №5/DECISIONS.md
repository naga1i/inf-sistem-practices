# Принципиальные проектные решения (Практическая работа №5)

## Решение 1. Строгий поэлементный разбор строки с диагностикой точной позиции ошибки
В методе `parseHours(String line)` используется вызов `line.trim().split(";", -1)` с отрицательным лимитом `-1`, чтобы не отбрасывать пустые элементы в конце строки (например, `"8;8;8;8;"`). В классическом цикле `for (int i = 0; i < parts.length; i++)` каждый элемент проверяется на формат целого числа и вхождение в диапазон `0..16`. При обнаружении ошибки генерируется `IllegalArgumentException` с указанием номера позиции `i + 1` (от 1 до 5), что полностью исключает частичную обработку невалидного табеля.

## Решение 2. Декомпозиция расчётов на циклы по массиву примитивов и выделение константы варианта
В соответствии с условием работы (без использования Stream API) методы `total`, `average`, `overtimeDays` и `weeklyOvertime` реализованы через явные циклы `for` с верхней границей `i < hours.length`. Правило индивидуального варианта №6 (недельная норма `WEEKLY_NORM_HOURS = 35` часов вместо 40) вынесено в именованную константу класса `TimesheetAnalyzer` и используется в методе `weeklyOvertime(int[] hours)` по формуле `Math.max(0, total(hours) - WEEKLY_NORM_HOURS)`.
